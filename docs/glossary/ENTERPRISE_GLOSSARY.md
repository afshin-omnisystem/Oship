# Enterprise Software & AI Architecture Glossary

## 1. Domain Vocabulary

- **ADR (Architecture Decision Record)**: An immutable document capturing an architectural decision, its context, and its consequences.
- **AI-Native Repository**: A repository whose layout, metadata, templates, and documentation are designed primarily for AI agent consumption and determinism.
- **Bounded Context**: An explicit boundary within domain-driven design where a specific domain model applies.
- **GitOps**: Operational model where declarative Git repository files act as the single source of truth for platform and project configurations.
- **YAML Frontmatter**: The structured metadata header block at the top of a Markdown document.
