# GitHub Discussions Structure & Governance

## 1. Overview

We use [GitHub Discussions](https://github.com/afshin-omnisystem/Oship/discussions) as our open community forum for architectural brainstorming, Q&A, and announcements.

## 2. Discussion Categories

| Category | Purpose | Template File |
| :--- | :--- | :--- |
| **`Announcements`** | Repository updates, phase transitions, and release notes. | `.github/DISCUSSION_TEMPLATE/announcements.yml` |
| **`Architecture Decisions`** | Early-stage discussions before formal ADR creation. | `.github/DISCUSSION_TEMPLATE/architecture-decisions.yml` |
| **`Ideas`** | Innovative proposals for capabilities and automation. | `.github/DISCUSSION_TEMPLATE/ideas.yml` |
| **`Q&A`** | Technical questions and onboarding help. | `.github/DISCUSSION_TEMPLATE/q-and-a.yml` |
| **`AI Agents & Automation`** | Discussions on prompt engineering, LLM contexts, and workflows. | `.github/DISCUSSION_TEMPLATE/ai-agents.yml` |
