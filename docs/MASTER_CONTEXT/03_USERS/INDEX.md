# Users Knowledge Domain — INDEX

## Purpose

Defines who Oship serves, their personas, goals, pain points, and journeys, ensuring every product and engineering decision is anchored in real user needs.

## Knowledge Scope

Covers user personas, demographics, jobs-to-be-done, journeys, experience flows, accessibility considerations, and user research findings. Interfaces with product (01) and design system (14).

## Responsibilities

The owners of this domain are responsible for:

- Maintain user personas and segmentation
- Document jobs-to-be-done and user goals
- Map primary user journeys and workflows
- Record research insights and feedback
- Ensure accessibility and inclusion requirements
