# Enterprise Wiki Structure & Taxonomy

## 1. Purpose

The enterprise Wiki serves as a human-friendly knowledge base, onboarding portal, and operational handbook. While `/docs` stores formal engineering contracts and `/architecture` stores blueprints, `/docs/wiki/` organizes accessible developer guides.

## 2. Wiki Hierarchy

```
docs/wiki/
├── WIKI_STRUCTURE.md        # This structural specification
├── INDEX.md                 # Master portal
├── architecture/            # Accessible architectural summaries for new developers
├── guides/                  # Step-by-step developer and AI agent guides
├── operations/              # Daily DevOps, triage, and deployment runbooks
└── onboarding/              # New engineer and AI agent setup checklists
```
