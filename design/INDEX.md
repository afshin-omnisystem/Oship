# Enterprise Design System & Brand Assets Index

This directory (`/design/`) houses our canonical brand assets, design system tokens, typography, color palettes, UX wireframes, and UI mockups.

```
design/
├── brand/           # Brand identity and guidelines
├── logo/            # Logo vector files and SVG assets
├── icons/           # Iconography library
├── typography/      # Typography tokens and font hierarchy
├── color-system/    # Color palettes and accessibility contrast ratios
├── design-system/   # Atomic UI components and design system tokens
├── wireframes/      # Low-fidelity wireframes
├── mockups/         # High-fidelity mockups
├── screens/         # Key user journey screen exports
├── animations/      # Interaction animations and motion specs
├── ux/              # User experience research and personas
└── ui/              # User interface style guides
```

Every subfolder contains a `.gitkeep` file to ensure deterministic structure preservation across git clones.
